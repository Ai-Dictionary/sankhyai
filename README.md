## 📘 Introduction
**SankhyAI by Mockmantra** is a next‑generation commercial course platform designed to help students **master technology and academics with industry mentors**. Hosted online, SankhyAI offers **budget‑friendly courses** in AI/ML, backend development, API development, Python, C, Java, mathematics, physics, and competitive academics, supported by **professional mentors and AI guidance**.  

Whether you’re preparing for **GATE, JEE, NEET, CET, JEMAT, or board exams**, SankhyAI provides a structured ecosystem where students can access live classes, AI‑powered study support, and personalized mentorship.

Official Website: [https://sankhyai.mockmantra.in](https://sankhyai.mockmantra.in)

## 🎯 Aim
Our aim is to create a **scalable, affordable, and intelligent learning platform** that:  
- Empowers students with **AI‑driven guidance** and mentor support.  
- Provides **exam preparation resources** for competitive and academic exams.  
- Connects learners with **industry mentors** for real‑world insights.  
- Makes professional education accessible in **Kolkata and beyond**.  

## 🛠️ How It Works
1. **Registration** → Visit [sankhyai.mockmantra.in](https://sankhyai.mockmantra.in) and fill out the registration form.  
2. **Demo Class** → Our admission team contacts you within 1–2 days for a demo session.  
3. **Enrollment** → After attending the demo, enroll in your chosen course.  
4. **Mentor Access** → Connect with mentors and gain access to course assets.  
5. **Learning Path** → Follow structured modules, live classes, and AI‑guided study support.  

📄 Fees, schedules, and brochures are available on the official website.

## 🚀 Features
- **AI‑Guided Learning** – Personalized study support powered by AI.

## 🧠 Technology Stack
- **Frontend:** Embedded JS (EJS), HTML/CSS, Vanilla JavaScript  
- **Backend:** Node.js  
- **Database/API:** JSON + TypeScript (security & API handling)  
- **Architecture:** JTEN (JSON‑Typescript‑Embedded‑Node)  
- **Software Model:** Recursive Agile Development
